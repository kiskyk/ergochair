# ErgoChair 設計（フェーズ1）

企画書「椅子選択支援アプリ ErgoChair」（2026-06-23）のフェーズ1実装。
費用ゼロ制約のため、サーバーレスの純フロントエンド静的Webアプリとする。

## 機能

1. 身長(cm)を入力（必須）
2. 座位の横向き写真を入力（任意。スマホカメラ/ファイル）
3. 写真あり: MediaPipe Pose Landmarker（ブラウザ内実行・無料）で膝・かかとの
   3Dワールドランドマークから下腿長を推定
4. 写真なし・検出失敗・推定値が妥当範囲(身長比0.20〜0.32)外: 数式モデルへ自動フォールバック
5. 結果表示: 推奨座面高（±許容範囲）、差尺、推奨机面高、使用した算出方法

## 計算式（人間工学の一般式）

- 下腿高 ≒ 身長 × 0.25（数式モデル）
- 座面高 = 下腿高（かかと接地基準、許容 −2cm/+1cm）
- 座高 ≒ 身長 × 0.55
- 差尺 = 座高 ÷ 3
- 机面高 = 座面高 + 差尺

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` | UI・MediaPipe解析・描画（1枚完結） |
| `calc.js` | 計算ロジック（純関数、ESモジュール） |
| `calc.test.mjs` | `node --test` による単体テスト |

- MediaPipe は CDN（jsdelivr）から読み込み。写真は外部送信されない
- ES モジュールのためローカル実行は `python -m http.server` 等で配信

## フェーズ2: 椅子の推奨リスト（楽天市場API）

- アプリ登録済み（2026-07-10、Web Application型、許可サイト: kiskyk.github.io、Ichiba APIスコープ、QPS 1）
- 商品検索APIで「オフィスチェア」を検索し、商品名・説明文から座面高範囲を
  正規表現で抽出（`parseSeatRange`）、推奨範囲と重なる商品のみ表示（`seatMatches`）
- 座面高を明記しない商品は除外。1件も該当しなければ楽天の検索URLへのリンクを提示
- キーはブラウザに渡さない。`/api/rakuten` への相対パスfetchを、本番は Cloudflare
  Pages Function（`functions/api/rakuten.js`、キーは環境変数Secret）、ローカルは
  `serve.py`（キーは `.env`）が中継してキーを付与する。リポジトリはprivateのまま公開可能

## 検証

- `node --test` が全件パス
- ブラウザで起動しコンソールエラーなし、身長のみ入力の経路で結果が表示される
